## 4A 基础检测规则

检测组件位于 `src/security/detection/`，不依赖 Flask 请求或数据库。当前规则编号：

- `PARAM_LENGTH`：参数长度异常。
- `SQL_KEYWORD`：SQL 关键字。
- `LOGICAL_COMBINATION`：引号、布尔逻辑和比较条件组合。
- `COMMENT_OR_SEPARATOR`：行注释、块注释或语句分隔符。
- `ENCODED_PAYLOAD`：可疑编码和重复编码。
- `SPECIAL_CHARACTER_RUN`：异常长度的连续特殊字符。

规则证据只保留长度、关键字或结构类型，不回显完整请求参数。4A 尚未接入现有页面和请求流程。

## 4B 风险评分与处置

4B 位于 `src/security/detection/scoring.py`。不同规则编号只计分一次，多个不同规则会获得有限组合加分。默认权重：

| 规则 | 分值 |
|---|---:|
| `PARAM_LENGTH` | 10 |
| `SQL_KEYWORD` | 25 |
| `LOGICAL_COMBINATION` | 30 |
| `COMMENT_OR_SEPARATOR` | 20 |
| `ENCODED_PAYLOAD` | 25 |
| `SPECIAL_CHARACTER_RUN` | 15 |

风险与动作映射：

| 总分 | 风险等级 | 处置动作 |
|---:|---|---|
| 0 | 无风险 | `allow` |
| 1–24 | 低风险 | `allow` |
| 25–59 | 中风险 | `alert` |
| 60–100 | 高风险 | `block` |

未知规则默认计 10 分，总分封顶 100。评分结果保留命中规则、分值贡献和可读原因，4C 将决定如何把动作接入请求流程以及请求频率规则。

## 4C 请求频率与执行处置

4C 在 `before_request` 阶段检查以下路由：

- `/articles` 的 `q` 和 `category`。
- `/demo/sql-injection` 的 `q`。

`scenario` 等控制参数不参与内容检测，登录密码也不会进入检测流程。

频率规则使用内存滑动窗口：

- 同一登录用户或来源地址、同一路由。
- 60 秒内第 5 次命中规则的请求触发 `REQUEST_FREQUENCY`。
- 频率规则默认贡献 40 分。
- 窗口状态在应用重启后清空，后续日志持久化由 4D 完成。

请求处置：

- 无风险、低风险：继续执行。
- 中风险：记录告警决策并继续执行。
- 正常业务路由高风险：在查询前返回 403 安全拦截页。
- 漏洞模式下受控演示高风险：降级为教学告警后允许运行。
- 安全模式下的演示请求本身不执行查询。

## 4D 载荷脱敏与检测日志

4D 使用 `src/security/detection/masking.py` 对请求参数生成不可还原的结构摘要，例如：

```text
q{len=12, alpha=11, digit=0, space=1, quote=0, symbol=0, control=0}
```

日志不会保存原始关键词、编码字符串或完整载荷。多个参数会分别记录名称、序号、长度和字符类别。

`src/services/detection_logs.py` 将以下字段写入 `detection_logs`：

- `attack_type`：SQL 注入、编码绕过、高频请求或异常输入分类。
- `endpoint`：实际目标路由。
- `payload_masked`：不可还原的参数结构摘要。
- `risk_level`：`low`、`medium` 或 `high`。
- `score`：4B 总风险分值。
- `action`：实际执行的 `allow`、`alert` 或 `block`。
- `created_at`：数据库生成的记录时间。

只有命中规则的请求才写入检测日志，正常参数和空值不会生成记录。

## 5A 安全模式加固

5A 的主要加固措施：

- 所有正常业务查询继续使用固定 SQL 结构和参数绑定。
- 文章搜索使用独立只读数据库连接，只允许读取文章展示字段和用户显示名。
- 禁止文章查询读取密码哈希、角色和日志等敏感字段。
- 只读连接同时启用 `query_only`、只读 URI 和 SQLite authorizer。
- 搜索关键词最长 80 个字符，文章分类最长 40 个字符。
- 输入不再静默截断；超长、控制字符和未知分类返回统一 400 页面。
- 用户名和密码长度显式校验，非法凭据仍返回统一登录失败提示。
- 增加 CSP、`nosniff`、禁止 iframe、无来源信息和 HTML 禁止缓存响应头。
- 增加统一 400、404、500 页面，内部异常和堆栈不回显给用户。

核心代码：

- `src/security/validation.py`
- `src/services/articles.py`
- `src/app.py`
